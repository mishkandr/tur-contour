# ТурКонтур

MVP для аналитика Международной академии гостеприимства. Пилотный сценарий охватывает Владимир, Суздаль и Кидекшу. Приложение связывает изменения в источниках с готовностью туристических программ и позволяет сравнить варианты пересмотра.

## Запуск

Нужен Node.js 22 или новее. Дополнительные пакеты устанавливать не требуется.

- На macOS откройте «Launch.command». Сервер выдаст свободный локальный адрес и откроет его в браузере.
- Из терминала выполните `node server.mjs` в папке проекта и откройте [http://127.0.0.1:4173](http://127.0.0.1:4173).
- Для разбора запросов моделью запустите Ollama с моделью `qwen3.5:4b`. Другую локальную модель можно выбрать через `TUR_OLLAMA_MODEL`. Если модель недоступна, включается ограниченный разбор по ключевым словам.

## Демо для защиты

1. На вкладке «Мониторинг» откройте программу Владимир → Суздаль для группы из Китая из 18 человек. Во втором дне есть Суздальский кремль.
2. Вернитесь в «Мониторинг» и нажмите «Снизить лимит в демо». Сервис прочитает вторую версию учебного аудита и запишет изменение 25 → 12 человек. Программа группы из 8 человек сохранится.
3. Нажмите «Сравнить сценарии». Сравните замену объекта и два сеанса по 9 человек. Во втором случае аналитик должен согласовать два слота с музеем.
4. На вкладке «Статистика» нажмите «Минимум ночёвок за три года». Проверьте период и ссылки на источники. На вкладке «Данные и методика» можно обновить внешние ряды и посмотреть журнал.

Вкладка «Маршрут» позволяет менять дату, размер и профиль группы, интересы и длительность. Полный черновик можно поставить на мониторинг. Программа для группы из Китая включает названия на упрощённом китайском и условия, требующие подтверждения.

## Происхождение данных

- Росстат через документированный API Roschart. Показатели «Численность размещённых лиц» и «Число ночёвок» по Владимирской области, выпуск `SR_mes_sub_09-2026`. Месячные значения получены как разности накопительных итогов. Начальный снимок сохраняется при сбое источника. Выпуск настраивается через `TUR_ROSSTAT_EDITION`. Встроенная интеграция опрашивает выбранный выпуск.
- Wikidata через Wikibase API. Координаты и названия для части каталога. Для объектов опубликованы ссылки на сайты музеев и поставщиков или карточки Wikidata.
- Методика и контрольные объекты из двух таблиц МАГ. Условия визита в `data/demo-audit*.json` — учебные значения. Часы, лимиты, транспорт, бронь и язык обслуживания требуют подтверждения перед реальной поездкой.
- Внешние источники проверяются при запуске и раз в шесть часов работы сервера. Снимки, журнал и программы на контроле хранятся в `.runtime/state.json`. Новый вид маршрута остаётся черновиком для решения эксперта.
