# ТурКонтур

ТурКонтур помогает аналитику Международной академии гостеприимства разобраться, какие готовые туристические программы затронуло изменение и как их скорректировать. Пилотный сценарий охватывает Владимир, Суздаль и Кидекшу.

На карте можно переключать дни и группы, открывать паспорта объектов и сравнивать две версии программы. Если карта улиц недоступна, приложение показывает локальную схему с теми же точками и линиями переездов.

## Запуск

Нужен Node.js 22 или новее. Дополнительные пакеты устанавливать не требуется.

- На macOS откройте «Launch.command». Сервер выдаст свободный локальный адрес и откроет его в браузере.
- Из терминала выполните `node server.mjs` в папке проекта и откройте [http://127.0.0.1:4173](http://127.0.0.1:4173).
- Для разбора запросов моделью запустите Ollama с моделью `qwen3.5:4b`. Другую локальную модель можно выбрать через `TUR_OLLAMA_MODEL`. Если модель недоступна, включается ограниченный разбор по ключевым словам.

## Демо для защиты

1. На вкладке «Карта» выберите второй день программы группы из 18 человек. Нажмите на Суздальский кремль в списке точек, чтобы увидеть его на карте и открыть паспорт.
2. Нажмите «Снизить лимит в демо». Сервис прочитает вторую версию учебного аудита и запишет изменение 25 → 12 человек. Программа группы из 8 человек сохранится.
3. Переключите «Замена объекта» и «Два сеанса». Сравните точки и расписание. Два сеанса по 9 человек нужно согласовать с музеем.
4. На вкладке «Статистика» нажмите «Минимум ночёвок за три года». Проверьте период и ссылки на источники. В «Источниках» можно обновить внешние ряды и открыть журнал.

Вкладка «Маршруты» позволяет менять дату, размер и профиль группы, интересы и длительность. Полный черновик можно поставить на мониторинг. Программа для группы из Китая включает названия на упрощённом китайском и условия, требующие подтверждения.

## Роль ИИ

Локальная Qwen помогает разобрать свободный запрос на русском и выбрать показатель, период или нужный раздел. Программа загружает данные, рассчитывает показатели, сравнивает версии и проверяет выполнимость маршрута по заданным ограничениям. Аналитик утверждает итоговую программу.

## Происхождение данных

- Росстат через документированный API Roschart. Показатели «Численность размещённых лиц» и «Число ночёвок» по Владимирской области, выпуск `SR_mes_sub_09-2026`. Месячные значения получены как разности накопительных итогов. Начальный снимок сохраняется при сбое источника. Выпуск настраивается через `TUR_ROSSTAT_EDITION`. Встроенная интеграция опрашивает выбранный выпуск.
- Wikidata через Wikibase API. Координаты и названия для части каталога. Для объектов опубликованы ссылки на сайты музеев и поставщиков или карточки Wikidata.
- Методика и контрольные объекты из двух таблиц МАГ. Условия визита в `data/demo-audit*.json` — учебные значения. Часы, лимиты, транспорт, бронь и язык обслуживания требуют подтверждения перед реальной поездкой.
- Внешние источники проверяются при запуске и раз в шесть часов работы сервера. Снимки, журнал и программы на контроле хранятся в `.runtime/state.json`. Новый вид маршрута остаётся черновиком для решения эксперта.

## Источники карты

- Карта улиц и реки используют данные [OpenStreetMap](https://www.openstreetmap.org/copyright). Для переездов между городами используются сохранённые линии [OSRM](https://project-osrm.org/). Соединения между отдельными остановками внутри города показаны пунктиром по прямой.
- Координаты 20 объектов и пяти населённых пунктов лежат в `data/map.json` со ссылками на источники. Для двух ресторанов показаны координаты комплекса, где они находятся.
