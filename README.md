# ТурКонтур

ТурКонтур помогает специалистам по развитию туризма выяснить, какие программы затронуты изменением условий посещения, пересчитать маршрут и подготовить решение для региона. Команда №19 разработала MVP для Международной академии гостеприимства (МАГ). Пилотный регион — Владимирская область.

[Открыть MVP](https://tur-contour.203.18.98.125.sslip.io/) · [Скачать датасет пилота](https://tur-contour.203.18.98.125.sslip.io/api/pilot-dataset.csv)

## Демо за 7 минут

1. **0:00–1:00 · Задача.** Меняется график или вместимость объекта. Специалисту нужно понять, какие маршруты пересмотреть, и решить, как сохранить программу поездки.
2. **1:00–3:00 · Изменение и источник.** В «Источниках» откройте «Журнал изменений» → «Учебный пример». Запустите пример, если он ещё не активирован. Учебный лимит Суздальского кремля снижается с 25 до 12 человек. Группа из 18 требует пересмотра, группа из 8 укладывается. В паспорте объекта покажите источник и условия, которые нужно уточнить. [Источники и журнал](https://tur-contour.203.18.98.125.sslip.io/#sources) · [Учебная программа на карте](https://tur-contour.203.18.98.125.sslip.io/#impact?program=group-cn)
3. **3:00–5:30 · Решение.** В сравнении условий выберите «Учебный расчёт». После изменения лимита выполнима 1 программа из 2. Покажите замену объекта и два сеанса. Два сеанса по 9 человек дают 2 из 2 по расчёту. Специалист подтверждает оба сеанса у музея. На учебной карте нажмите «Открыть программу», затем покажите «Программа на китайском» и её выгрузку. [Сравнение условий](https://tur-contour.203.18.98.125.sslip.io/#impact?analysis=1)
4. **5:30–7:00 · Архитектура и проверка.** Объясните работу расчёта, роль ИИ и решение специалиста. Назовите целевые показатели пилота.

## Как работает

Код обновляет данные, фиксирует изменения, проверяет даты и ограничения и рассчитывает варианты программ. Для смыслового сравнения используем **ступень 3**. Один запрос к локальной модели через Ollama ранжирует от двух до шести рассчитанных вариантов по пожеланию специалиста. Сервер сверяет ответ с этими вариантами. При сбое модели специалист сравнивает их вручную. **Уровень свободы 4** означает, что система предлагает варианты, а специалист проверяет условия и принимает решение.

## Данные и метрики

- **Каталог пилота** содержит 30 объектов. Для 28 есть опубликованные условия или примечания. В паспортах указаны источник, дата сверки и вопросы к поставщику. Доступность конкретного сеанса, вместимость организованной группы и перевод подтверждает поставщик. [Каталог пилота](https://tur-contour.203.18.98.125.sslip.io/#catalog) · [CSV в репозитории](data/pilot-dataset.csv)
- **Мониторинг** использует статистику размещения Росстата через Roschart и справочные сведения Wikidata. Графики и правила визита берутся из публикаций объектов. Учебное изменение лимита и данные учебных групп помечены в интерфейсе. [Roschart](https://roschart.ru/docs) · [График ВСМЗ](https://vladmuseum.ru/ru/posetitelyam/times/index_rezim.php)
- **Проверка гипотезы.** Цель пилота — сократить медианное время пересмотра на 30% при сохранении качества ручной проверки. Порог для ИИ — первая рекомендация подходит минимум в 18 из 20 заданий, ложных подтверждений критических условий в этой выборке — 0. Эти показатели предстоит измерить со специалистами.

## Локальный запуск

Нужен Node.js 22 или новее. Зависимостей npm нет.

```sh
node server.mjs
```

Откройте [http://127.0.0.1:4173](http://127.0.0.1:4173). Для повторного прогона учебного примера с чистым состоянием используйте `TUR_STATE_DIR="$(mktemp -d)" node server.mjs`. Тесты запускаются командой `node --test`. Копию датасета можно пересобрать командой `node scripts/export-pilot-dataset.mjs`. [Настройка источников, модели и сервера](deploy/README.md)

Данные карты предоставляют OpenStreetMap и GeoNames. Геометрия отдельных переездов получена через OSRM. Прогноз — Open-Meteo, CC BY 4.0. Лицензии Leaflet, Inter и PT Serif находятся рядом с файлами. [OpenStreetMap](https://www.openstreetmap.org/copyright) · [GeoNames](https://www.geonames.org/export/) · [OSRM](https://project-osrm.org/) · [Open-Meteo](https://open-meteo.com/en/docs)
